# 웹캠 배구 실행 안내

## 웹에서 실행

- 게임: https://junho1-commits.github.io/webcam-volleyball/
- 처음 영상부터: https://junho1-commits.github.io/webcam-volleyball/intro.html

최신 Chrome 또는 Edge에서 실행하세요. 웹캠 게임을 시작할 때 카메라 사용을 허용하면 됩니다. 웹캠 영상은 브라우저 안에서 처리하며 서버로 전송하지 않습니다.

이 공개 저장소에는 실행 파일만 포함합니다. 아래 개발 안내에서 언급하는 내부 문서·제작 원본·시험 녹화·로컬 도구는 개발 PC에만 보관합니다. 외부 엔진 라이선스는 `THIRD_PARTY_NOTICES.md`와 `LICENSES/`에 있습니다.

> 개발을 이어서 하는 Claude·GPT는 **`docs/인수인계.md`**부터 읽는다(지금 상태·할 일·파일 담당). 지시서는 `docs/지시서/`.

`실행.bat`을 실행하고 **경기하기 → 인원 → 선수 → 시작!** 순서로 고른다. 처음 사용하는 학생은 **연습하기**로 동작을 익힐 수 있다. 영상은 브라우저 안에서만 처리되며 저장되거나 서버로 전송되지 않는다. 웹캠 경기의 명장면 사진(결과 화면 사진첩)도 메모리에만 있다가 새 경기·처음 화면으로 가면 지워진다. 시작 화면 구석의 **선생님 설정**에서 끌 수 있다.

3D 엔진(three.js)과 동작 인식 엔진·모델(MediaPipe)은 `vendor/` 폴더에 들어 있어 **인터넷 없이도 실행된다**. 이 폴더를 지우거나 빼고 복사하면 게임이 켜지지 않는다. 코드를 고친 뒤에는 브라우저에서 Ctrl+Shift+R로 새로고침한다.

## 실행 PC 그래픽 설정

1. Windows **설정 → 시스템 → 디스플레이 → 그래픽**으로 이동한다.
2. Chrome을 추가하고 옵션을 **고성능(NVIDIA)** 으로 지정한다.
3. Chrome 주소창에서 `chrome://gpu`를 열어 NVIDIA GPU가 활성화됐는지 확인한다.
4. 게임에서 `F2`를 누르면 실제 WebGL GPU 이름과 성능을 볼 수 있다. NVIDIA가 아니면 게임 오른쪽 위에 경고가 나온다.

## 주소 옵션과 단축키

- `?pose=cpu-lite` / `cpu-full` / `gpu-lite` / `gpu-full`: 포즈 모델 실행 조합. 이 PC의 합성 영상 측정에서 가장 빨랐던 `gpu-full`이 기본이다.
- `?quality=high|medium|low`: 시작 화질. 기본은 높음.
- `?perf=1`: 성능 표시를 처음부터 연다.
- `?mirror=1`: 판정 동작이 아닐 때 웹캠 팔 각도를 GLB 캐릭터에 시험 적용한다.
- `/replay.html`: 테스트 페이지에서 V로 녹화한 관절 파일이나 **휴대폰 영상(mp4/webm/mov)**을 열어 동작·서브 인식률을 계산하고 기준값을 조정한다. 영상은 처음 3초 차렷, 정면, 허리~머리 위 손이 보이게 찍는다.
- `/benchmark.html`: 실행 PC에서 CPU/GPU × lite/full 포즈 처리 속도를 비교한다.
- `F2`: 성능 표시, `F3`: 화질을 한 단계 수동으로 올린다. 성능이 3초 동안 목표보다 10% 이상 낮으면 자동으로 한 단계 내려간다.
- `F4`: GLB 검수용으로 1P의 11개 동작을 순서대로 미리 본다.

## 아바타 제작

현재 `assets/characters/ara.glb`, `min.glb`, `sori.glb`, `jun.glb`는 프로젝트에서 직접 생성한 경량 휴머노이드 프로토타입이다. 네 캐릭터는 같은 Mixamo식 뼈 이름과 11개 동작을 공유하며, 머리 모양·피부색·팀 유니폼·등번호로 구분된다. `tools/build_avatar.py`를 실행하면 캐릭터와 동작 GLB가 재생성된다. 외부 GLB가 없거나 로드에 실패해도 기존 도형 아바타로 경기가 계속된다.

`assets/characters/ara-hq.glb`가 있으면 아라는 이 고품질 모델을 우선 사용한다. 런타임 파일은 1024×1024 질감으로 최적화되어 약 2.24MB이며, 로드 실패 시 `ara.glb`로 자동 전환된다. 모든 모델은 로드할 때 키 1.75m와 발바닥 y=0으로 정규화된다.

콘셉트와 같은 고정밀 제작본으로 교체할 때 선생님 로그인이 필요한 단계:

1. Meshy/Tripo 또는 Blender에서 `art/concept` 3면도를 바탕으로 모델 제작
2. Mixamo에서 자동 리깅 및 기본 동작 다운로드
3. Blender에서 배구 동작과 접촉 순간 조정
4. Draco 메시 압축과 KTX2 질감으로 GLB 내보내기(각 5MB 이하)
